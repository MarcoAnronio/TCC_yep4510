# Interface YEP 4510

Aplicação React do sistema de intercâmbio. As instruções de configuração, execução e testes estão no [README principal](../../../README.md).

- `src/pages`: telas da aplicação.
- `src/components`: layout e navegação compartilhados.
- `src/services/api.js`: cliente HTTP e envio do token do usuário.
- `public/images` e `public/icons`: recursos visuais.

Configure apenas o endereço público da API em `.env.local`, seguindo `.env.example`. Não inclua chaves ou senhas nas variáveis do React.
